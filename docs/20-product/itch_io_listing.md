## itch.io Quality Guidelines Summary

### Before Publishing

- [ ] Page is complete with all images, files, classifications
- [ ] Cover image uploaded
- [ ] Screenshots provided
- [ ] Metadata is accurate
- [ ] Only tested platforms selected

### Content Rules

| Do | Don't |
|----|-------|
| Use relevant tags | Tag-spam unrelated terms |
| Prefer suggested tags | Add your name/title as tags |
| Mark adult content if applicable | Use explicit cover images |
| Upload files directly to itch.io | Use third-party download links |
| Create one page per distinct project | Create "reskins" or duplicate pages |

### Platform Selection

Only select a platform if you have an **executable that runs directly on that OS**.

- HTML file viewable in browser → select HTML5/Web
- .exe for Windows → select Windows
- PNG assets → select "Graphical Assets" from dropdown, NOT Windows

### Tags

- Prefer suggested tags over custom ones
- Don't duplicate metadata classifications as tags
- Don't use synonyms (zombies AND zombie)
- Don't use project name as tag

### AI Disclosure

If using generative AI (ChatGPT, DALL-E, Midjourney, Stable Diffusion):
- Must tag in AI Disclosure section
- Especially strict for asset pages

Traditional game AI (pathfinding, procedural generation, difficulty adjustment) does NOT require disclosure.

### Sales Rules

- Don't have perpetual sales (just lower the price)
- Don't manipulate base price + sale to fake discounts
- Don't run sales too frequently

### Game Jams

- Only submit to relevant jams
- Don't create jams to promote your own project
- Don't create jams to solicit free work

### Prohibited

- Malware, spyware, adware
- Misleading content or fake screenshots
- Impersonating other creators
- Real-money gambling mechanics
- Pyramid schemes / buy-in contests
- Obtrusive ads or unnecessary login walls
- Shock images, loud noises, flashing imagery
- Mass AI-generated content spam

### Consequences of Violations

- Page removed from browse/search/recommendations
- Page still accessible via direct URL
- Account may lose jam privileges
- Account may be suspended
- Payments may be disabled
